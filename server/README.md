# Локальный сервер Kotatsu

Здесь находится локальный вариант сайта и сокращателя. Сервер использует только встроенные модули Node.js, хранит ссылки в `server/data/links.json` и раздаёт файлы приложения из корня проекта.

Требуется Node.js 18 или новее. В терминале из корня проекта запусти:

```sh
node server/server.mjs
```

Открой <http://localhost:8788>. Кнопка «Скопировать ссылку» создаст локальный адрес вида `http://localhost:8788/<id>`. Он открывается только там, где запущен этот сервер; для публичной рассылки настрой Cloudflare Worker.

Не публикуй папку `server/data`: в ней лежат полные ссылки на раскладки. Она исключена из Git.

Можно изменить порт и адрес коротких ссылок переменными `PORT`, `HOST`, `APP_ORIGIN` и `SHORT_ORIGIN`. Для обычного запуска оставь значения по умолчанию и открывай именно `localhost`, а не `127.0.0.1`.
