# Карта события · ИТМО

Статическая карта первого и второго этажей корпуса ИТМО на Ломоносова, 9. План помещений берётся из `data/building_273.geojson`, граф проходов — из [API навигации ИТМО](https://my.itmo.ru/api/navigator/buildings/273/transition); подложка — OpenStreetMap, рендеринг — MapLibre GL JS.

## Редактор

- Выберите этаж и помещение на карте или в списке.
- Назначьте помещению одну из зон мероприятия.
- Название события и разметка сохраняются в `localStorage` текущего браузера.
- Кнопки «Экспорт» и «Импорт» позволяют перенести раскладку между устройствами в JSON-файле.

Для предпросмотра запустите любой статический HTTP-сервер из корня проекта, например `python -m http.server 8000`, и откройте `http://localhost:8000`. Открывать `index.html` через `file://` нельзя: браузер блокирует загрузку GeoJSON.

## GitHub Pages

Workflow в `.github/workflows/pages.yml` публикует корень репозитория на GitHub Pages при push в `main`. В настройках репозитория откройте **Settings → Pages → Build and deployment → Source: GitHub Actions**. Ручной запуск доступен во вкладке **Actions → Publish GitHub Pages → Run workflow**.

Это клиентский редактор без общего сервера: раскладки не синхронизируются между пользователями автоматически. Для совместной работы экспортируйте и передавайте JSON-файл.
