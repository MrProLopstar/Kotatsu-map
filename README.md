# Карта события · ИТМО

Редактор планов шести корпусов из навигатора ИТМО. Корпус и этаж выбираются слева; этажи и номера помещений приходят из векторных тайлов ИТМО. Уличной подложки OSM и маршрутов нет. Метаданные корпусов хранятся локально в `data/buildings.js`, а номера аудиторий и иконки — в тайлах и локальном каталоге `assets/`.

## Редактирование

- Добавляйте зоны-квадраты, двигайте их за заливку, меняйте контур за угловые ручки и добавляйте вершины нажатием `+` на ребре.
- Переименовывайте и перекрашивайте зоны; раскладка автоматически сохраняется в текущем браузере отдельно по корпусам и этажам.
- Переключайтесь в режим «Просмотр», чтобы скрыть редактор и получить список занятых корпусов с кнопками только занятых в них этажей.
- Переключайте светлую и тёмную тему кнопкой в шапке; без сохранённого выбора используется тема системы. Интерфейс использует системный шрифт.
- Кнопка «Скопировать ссылку» создаёт короткую ссылку на отдельный просмотр раскладки. Снимок сжимается в URL; старые ссылки тоже открываются. Просмотр доступен без редактора, JSON можно скачать.
- Чтобы использовать публичный Cloudflare Worker, настрой D1 и вставь его адрес с `/api/links` в `data/share-config.js`; инструкция и миграция — в `cloudflare/`. Без настроенного Worker карта использует clck.ru как запасной сервис.
- Для локальной версии запусти `node server/server.mjs` из корня проекта и открой <http://localhost:8788>. Она сохраняет короткие ссылки в `server/data/links.json`; подробности — в `server/README.md`.
- Отменяйте и повторяйте изменения кнопками «Назад»/«Вперёд» или `Ctrl+Z`, `Ctrl+Y` (`Cmd+Z` и `Cmd+Shift+Z` на macOS).
- Импортируйте и экспортируйте раскладку в JSON, чтобы передать её на другое устройство. Формат сохраняет корпус и уровень; старые раскладки для Ломоносова, 9 продолжают импортироваться.

Откройте проект через статический HTTP-сервер из корня репозитория, например `python -m http.server 8000`, затем зайдите на `http://localhost:8000`. Страница публикуется на GitHub Pages. Короткий SHA последнего развёрнутого коммита показывается внизу слева.

Данные зон редактора хранятся в браузере. Короткие ссылки содержат снимок раскладки в хранилище выбранного сервиса; обладатели ссылки могут просматривать снимок и скачивать JSON. Cloudflare Worker и локальный сервер хранят ссылки бессрочно, если их не удалить вручную. Список корпусов берётся из публичного API навигатора ИТМО и поставляется вместе со страницей; сами планы и номера аудиторий загружаются с тайлового сервера ИТМО.
