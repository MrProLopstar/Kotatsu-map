# Карта события · ИТМО

Редактор плана первого и второго этажей здания на Ломоносова, 9. План, номера помещений и точки интереса берутся из векторных тайлов ИТМО (`data/itmo-style.json`). PNG-иконки и глифы шрифта SF Pro Text Semibold лежат в `assets/` и отдаются GitHub Pages с этого сайта. Уличной OSM-подложки и графа маршрутов нет.

## Редактирование

- Добавляйте зоны-квадраты, двигайте их за заливку, меняйте контур за угловые ручки и добавляйте вершины нажатием `+` на ребре.
- Переименовывайте и перекрашивайте зоны; раскладка автоматически сохраняется в текущем браузере.
- Отменяйте и повторяйте изменения кнопками «Назад»/«Вперёд» или `Ctrl+Z`, `Ctrl+Y` (`Cmd+Z` и `Cmd+Shift+Z` на macOS).
- Импортируйте и экспортируйте раскладку в JSON, чтобы передать её на другое устройство.

Откройте проект через статический HTTP-сервер из корня репозитория, например `python -m http.server 8000`, затем зайдите на `http://localhost:8000`. Страница опубликована на GitHub Pages. Короткий SHA последнего развёрнутого коммита показывается внизу слева.

Данные зон хранятся только в браузере пользователя; автоматической синхронизации между людьми нет. Подложка и номера аудиторий загружаются с сайта навигации ИТМО.
